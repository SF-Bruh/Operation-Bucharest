# Velkomstvideo

Her skal to filer ligge, begge lavet af `tools/encrypt-greeting.mjs`:

- `greeting.enc`: videoen, krypteret
- `keys.json`: videoens nøgle, låst én gang pr. person med deres kode

Læg aldrig selve `.mp4`-filen eller kodefilen her eller andre steder i repoet.
Mangler filerne, springer siden bare videoen over.
