Operation Bucharest · Builder

Skriv felterne på hjulet, giv hver spiller en kode og sæt deres odds. Byg derefter data.js og læg den på GitHub ved siden af index.html.

Hold det her privat. Alt sker i din browser, og intet sendes nogen steder. Læg kun data.js på GitHub – ikke denne side og ikke din opsætningsfil, ellers kan de andre se oddsene.

Felter og odds

Rækker er felter, kolonner er spillere. Tallene er chancer i procent. Summen behøver ikke ramme 100 – den bliver omregnet. 0 betyder, at feltet aldrig rammer for den spiller.

Byg og eksportér

Krypterer hver spillers hjul med deres egen kode. Uden koden kan ingen læse felter eller odds i filen.

Test en kode

Tjekker den byggede fil, præcis som hjulet gør.

Kodeliste

Send hver spiller kun deres egen kode.

Gem din opsætning

Siden husker dit udkast i denne browser. Gem også en kopi som fil, så du kan rette i den senere. Filen indeholder koder og odds i klartekst – læg den ikke på GitHub.

  1. Byg data.js og hent filen.
  2. Gå til dit repo på GitHub, vælg Add file → Upload files og upload den nye data.js (den erstatter den gamle).
  3. Vent et minuts tid, og genindlæs hjulet. Gamle koder holder op med at virke, nye virker.
